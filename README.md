# 🏥 ClinicaApp

Sistema de gestión de turnos médicos desarrollado en Java ☕  

---

## 🚀 ¿Funcionalidades?

👤 Registrar pacientes  
🩺 Registrar médicos  
📅 Asignar turnos  
❌ Cancelar turnos  
🔄 Cambiar estado de citas  
📋 Consultar pacientes, médicos y turnos  
💾 Guardar información automáticamente con archivos CSV  

---

## 🛠️ Tecnologías

- Java
- POO
- IntelliJ IDEA
- CSV
- Collections
- LocalDateTime
